# RepoPlay v0.1 scope

Local Next.js application in its own directory. The adjacent AgentConfigScore checkout is read-only demo material; its uncommitted changes are excluded. Source snapshots come from Git objects at public commit `633ccef39a89ba79592d90a68f5410f57bb8bb53`, confirmed through GitHub on 2026-10-07.

Deliver three short, editorially source-checked tours using one strict Tour schema and renderer. All state diagrams are illustrative, never execution traces. No accounts, database, external publishing, remote execution, model calls during verification, or agents.

Use plain CSS, system fonts, bounded GitHub reads, server-side replaceable model adapter, local JSON import/export. New generation is disabled until project-specific environment variables are configured. Local imports cannot establish upstream provenance and are labeled accordingly. Public hosting, repository creation, naming clearance, real-user validation, and human editorial review remain release work.
